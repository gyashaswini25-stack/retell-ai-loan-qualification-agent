# Project Workflow

1. The customer opens the voice agent.
2. The agent greets the customer.
3. The agent asks questions about property and loan requirements.
4. The agent collects the customer's answers.
5. The agent provides an initial assessment.
6. A loan expert may contact the customer for further evaluation.

## Technology
- Retell AI
- AI-powered conversational voice agent

## Current Status
The agent is configured in Retell AI. The shared browser demo is still being tested.
